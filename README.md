# Interactive Play – Xalingo Brinquedos

Versões web (HTML, 3D e realidade aumentada) dos produtos STEAM Interactive Play.
Publicado em https://inovacaoxalingo.github.io/interactive-play/

| Pasta | Produto |
|---|---|
| `corpo-humano/` | Quebra-cabeça Conhecendo o Corpo Humano (ref. 53309) |
| `conhecendo-os-planetas/` | Quebra-cabeça Conhecendo os Planetas (ref. 53265) |
| `arca-de-noe/` | Quebra-cabeça para colorir Arca de Noé (ref. 2084.3), marca Arca Toys — página própria, fora da lista da entrada |

Cada produto fica em uma pasta própria, com o seu `index.html` e a pasta `assets/`.

`assets/aceite.js` (aviso para o adulto e escolha da contagem anônima) e `privacidade.html` são comuns a todos os produtos.
`arca-teste-q7m2/` só redireciona o endereço de teste antigo para `arca-de-noe/`.
